## 怎么读

想马上做决定，读「怎么做」和「说人话」。想了解效果有多大、研究做在谁身上，看「收益」「证据等级」和「来源」。价格、份量和训练计划里的示例可以按自己的情况重算。

- **A**　用于与问题直接相关的多项试验或系统综述支持的结论。
- **B**　用于较小的试验、观察研究或需要外推的结论。
- **C**　用于主要依据专业共识、临床指南或官方计划的执行建议。

字母是本项目的编辑分级，标在它所支持的具体结论上。官方标准、食物成分和示例算式，直接查出处或重算。
