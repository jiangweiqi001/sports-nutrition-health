# 运动营养健康指南 · 515 题总目录

面向准备开始运动和已经规律运动的普通成年人。运动篇涵盖抗阻训练、拉伸与活动度、有氧训练。有氧覆盖快走、走跑交替、跑步入门、骑行、游泳和室内器械，并延伸到公路半马、全马和越野跑。健康以训练中的恢复、伤病、运动安全和返训为主，另设常见慢病与运动。孕产、中老年等人群在运动安排或就医条件有实质差异时单列。

下表和各组数字都含首版条目。点击题号可直接跳到正文。保留首版题号，新题从 Q41 起连续编号。

## 选题归属与证据核查

- 从 Q401 起，新增选题先从真实提问找起。查跑步和力量训练社区的公开问答、赛事 FAQ、医院或专业机构的常见问题，以及项目收到的读者反馈，优先收录在不同帖子、答疑或反馈中反复出现的问题。
- 选题时记下原问题链接或反馈出处，合并问法相近的问题，保留读者的用词、场景和实际困惑。各章题数用于安排篇幅。暂时找不到真实提问支撑的题目，可以暂缓收录。社区问答用于发现问题，正文的建议另查指南、共识和研究。
- 每题对应一个读者要做的决定。选题覆盖建立日常活动习惯、提升体能和准备比赛等目标。有氧入门和越野跑优先从真实提问补充，短距离越野和日常山径活动也在范围内。不同项目共用做法时合写，训练安排、摄入量或求助条件确有区别时再拆题。
- 运动篇管练什么、练多少、用多大强度和怎么进阶。拉伸章管活动范围和运动前后的安排。营养篇管吃喝、采购、补给和补剂。健康篇管症状、风险、伤后或病后返训。兼练的课表放在抗阻章，兼练的吃喝放在训练饮食与补剂章。
- 例如高温跑步，怎么改配速放有氧训练，怎么计划喝水按场景放训练饮食或长跑营养，什么时候改期、停练或求助放训练相关健康。正文之间按需要互链。
- 慢病条目围绕运动前要确认什么、训练怎样调整、要观察什么、何时停练或就医。相关药物只在它们会改变运动决策时提及，具体处置参照对应临床指南及个人医疗方案。
- 确定问题后，按二级主题检索证据。抗阻与活动度查运动医学立场和系统综述，有氧入门查身体活动指南及面向初学者的研究，公路跑步查大众跑者研究并用官方训练表作示例，越野跑结合对应地形、距离的研究及赛事与户外管理机构资料，营养查膳食指南和运动营养共识，健康及慢病按各病种查临床指南。逐题核对关键数字、适用人群、结果指标和安全线。 [首版证据选用与核查记录](evidence.md)
