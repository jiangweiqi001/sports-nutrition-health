# 证据选用与核查记录

1. **优先找专业机构和高质量综述。** 运动营养先查美国运动医学会、世界田联、国际奥委会等机构的指南、联合立场和共识，再结合相关的高质量系统综述与原始研究。涉及疾病、症状评估或用药时，优先查相应的临床指南。核对文件版本和勘误。
2. **优先选能直接回答问题的证据。** 比较研究对象、运动场景和实际测量的结果。面向普通成年人和大众跑者时，优先采用人群相近的研究。只能参考精英运动员、小样本试验或观察研究时，写清适用范围和不确定性。多个文件沿用同一份研究时，按同一证据核查。
3. **让关键说法能追溯。** 摄入量、效果数字和安全建议都链接到原文，尽量标出表格、图或章节。写明结果是研究测得的、专业机构建议的，还是为说明做法而举的例子。证据不足或结果不一致时，按证据能支持的范围措辞。
