每周只有两次时间，怎么开始练

适合想开始练力量、每周能留出两段约半小时的普通成年人。先安排两次能做完的全身训练，再用平时的空档补有氧。每周两次怎么起步

把两次训练排进日历

先选两个最容易守住的时段。每次留出热身和组间休息，从下肢、上肢推、上肢拉各选一个动作。下面是一种排法，每个主动作可从一到两组开始。

第一次

  • 下肢　坐站或蹲
  • 上肢推　俯卧撑或器械推胸
  • 上肢拉　弹力带或器械划船

第二次

  • 下肢　臀桥或髋铰链
  • 上肢推　选一种能做稳的推
  • 上肢拉　下拉或划船

居家可以从手边的器材选动作。去健身房时，先学会调座椅和试用器械。只能周末连练时，可以把两天最吃力的内容分开。

练完记三项，下次只调一项

记下动作、重量和每组次数。第一次用轻一点的负荷试动作，熟悉后再选重量。同一重量下各组次数都能做稳、还有余力时，可以小幅加重。如果某天时间更短，先选熟悉的动作，把需要较多热身和休息的内容留给较长的那次。

把有氧放进已有的空档

想增加日常活动，可以从通勤或午休的短段步行做起，按实际时长累计。走路已经费力时，先选短一点、方便返回的路线。
