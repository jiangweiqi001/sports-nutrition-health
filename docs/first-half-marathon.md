# 首半马从选计划到比赛当天

给已经能跑五公里、想准备第一次半马的成年人。先确认课表接得上，再把训练里试过的节奏、早餐和补给带到比赛。[Q23 用近期跑量选课表](../book/02-distance-running.md#q23)

## 选计划时，对照这三项

翻开最近几周的训练记录，写下一周跑几次、总跑量、最长一次跑多远。拿这三项对照课表第一周，再看离比赛还有多少周。平时只是偶尔跑一次五公里，可以先建立能重复的跑步安排。选比赛时，把分区起跑和分段关门时间也算进去。[Q23 课表起点](../book/02-distance-running.md#q23) · [Q131 每周三跑](../book/distance-running/01-planning.md#q131) · [Q125 核对关门时间](../book/distance-running/01-planning.md#q125)

## 在长跑里试一次早餐和补给

按预计过起点的时间倒推早餐，在一次已有的长跑里试熟悉的食物、份量和时间。按预计完赛用时查当届的饮料和食品，再试途中能耐受的补给。胶、含糖运动饮料和其他食物的碳水一起算。如果吃后反胃，下一次试跑先改一项。[Q26 早餐](../book/05-distance-running-nutrition.md#q26) · [Q21 途中补给](../book/05-distance-running-nutrition.md#q21) · [Q32 反胃时怎么试](../book/05-distance-running-nutrition.md#q32)

## 临赛回看训练记录，定下起跑目标

一起看近几周跑得是否连续、较长的几次跑后半段是否可控、跑完能否正常接下一次训练。状态反复或准备不足时，给自己放慢目标或换一场的选项。按课表倒推最后一次较长的跑，留出减量时间。[Q151 判断完赛准备](../book/distance-running/03-half-marathon.md#q151) · [Q171 倒推最后一次较长的跑](../book/distance-running/05-taper.md#q171)

## 比赛当天，按实际情况调整

- 吃训练中试过的早餐，带上试过的补给，出门前核对天气和赛事公告。[Q26 赛前早餐](../book/05-distance-running-nutrition.md#q26) · [Q21 首半马补给](../book/05-distance-running-nutrition.md#q21)
- 起跑拥挤或前几公里跑快了，先回到可控的用力程度。当天比训练时热，可以降低起跑目标。[Q175 起跑节奏](../book/distance-running/06-racing.md#q175) · [Q179 热天调整](../book/distance-running/06-racing.md#q179)
- 饮水按口渴或训练中估出的个人需求调整。出现胸口压迫、快晕倒或异常气短，立即停下并求助。[Q39 饮水与求助](../book/06-training-health.md#q39) · [Q353 现场求助](../book/training-health/06-emergencies-and-weather.md#q353)
