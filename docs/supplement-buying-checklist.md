# 补剂和装备，哪些可以先省下

买之前，先写下想解决的问题。吃不够蛋白质、晚上练完睡不着、跑后酸痛，是三个不同的问题。下表对应具体场景，适用条件和研究出处可点题号查看。

| 遇到的情况 | 先做什么 | 看哪一题 |
| --- | --- | --- |
| 全天蛋白质已经吃够，想再买 BCAA | 想增肌或练力量，可以先省下。正餐确实有缺口时，再按每 20 克蛋白质比较常吃的食物和蛋白粉。 | [Q18 BCAA](../book/04-training-nutrition.md#q18) · [Q16 蛋白质比价](../book/04-training-nutrition.md#q16) |
| 想增重，考虑买增肌粉 | 先稳住训练、记几周体重。吃不够时，拿自己吃得下的普通加餐与增肌粉比较实际份量、价格和携带便利性。 | [Q19 普通加餐还是增肌粉](../book/04-training-nutrition.md#q19) |
| 燃脂产品拿出汗或当天掉秤做宣传 | 看同一产品有没有较长期的对照研究，测过体脂、腰围和不良反应。只有出汗或体验视频时，可以先省下。 | [Q255 怎么核对燃脂宣传](../book/training-nutrition/05-supplement-purchasing.md#q255) |
| 训练前补剂只写一勺混合粉有多重 | 问清每份单项成分的量。再把咖啡、能量饮料和其他补剂里重复的成分按实际用量加总。 | [Q251 专有配方](../book/training-nutrition/05-supplement-purchasing.md#q251) · [Q254 叠加摄入](../book/training-nutrition/05-supplement-purchasing.md#q254) |
| 晚上训练，想靠含咖啡因的产品提神 | 如果晚上已经容易睡不着，先试省掉这类训练前补剂，把咖啡移到白天或选低咖啡因饮品。 | [Q20 晚练与咖啡因](../book/04-training-nutrition.md#q20) |
| 刚开始走跑，想一次买齐装备 | 先用穿得舒服的鞋和衣服，记下实际走跑时间。等有了具体不适或记录需求，再挑要添的东西。 | [Q408 走跑装备](../book/aerobic-training/01-getting-started.md#q408) |
| 训练后酸痛，想买按摩枪 | 先看是否只是常见的练后酸痛。想短时放松，可以比较手法、泡沫轴和按摩枪的舒适感和费用。伤处明显红肿、麻木或疼痛持续时，查看原题的评估条件。 | [Q321 按摩工具](../book/training-health/03-recovery.md#q321) · [Q323 练后酸痛](../book/training-health/03-recovery.md#q323) |

想试用某一种产品，可以先选一个观察指标和停用条件，记下试用前后的实际表现和花费。[Q253 怎么试用](../book/training-nutrition/05-supplement-purchasing.md#q253)
