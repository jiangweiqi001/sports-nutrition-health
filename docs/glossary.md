# 训练、营养与健康常用词

| 术语 | 读条目时怎么理解 | 看哪一题 |
| --- | --- | --- |
| 正式组 | 用来完成当天训练任务的一组。为适应动作或重量做的热身组另记。 | [Q68 热身](../book/resistance-training/04-session.md#q68) |
| 力竭、余力次数（RIR） | 力竭指按要求再也做不出下一次。余力次数是停组时估计还能做几次。例如余力约 2 次，就是估计还能用同样的动作做 2 次。 | [Q76 用余力决定停组](../book/resistance-training/05-progression.md#q76) |
| 主观用力程度（RPE） | 自己觉得有多费力。看课表时先确认它用哪种量表。跑步也可以用说话测试来感受强度。 | [Q140 用说话检查强度](../book/distance-running/02-workouts.md#q140) |
| 配速 | 完成一公里花多久。例如 6:30／公里表示每公里约 6 分 30 秒。 | [Q142 配速、心率和体感怎么选](../book/distance-running/02-workouts.md#q142) |
| 每小时碳水 | 途中从胶、饮料或食物摄入的碳水，按每小时实际吃喝的量加总。 | [Q27 换算补给](../book/05-distance-running-nutrition.md#q27) · [Q273 看标签](../book/distance-running-nutrition/03-carbohydrates.md#q273) |
| 碳水加载 | 在长时间比赛前调整几天的碳水摄入，以增加糖原储备。适不适合要看预计比赛用时和耐受。 | [Q25 赛前怎么安排主食](../book/05-distance-running-nutrition.md#q25) |
| 汗率 | 单位时间的出汗量，常用升／小时。可用类似环境下的训练数据粗估，跑中喝多少还要结合口渴和个人情况。 | [Q31 出汗量怎么算](../book/05-distance-running-nutrition.md#q31) |
| 运动中的相对能量缺乏（REDs） | 长期或严重的低能量可用性引起的一组问题，可影响身体功能、心理状态和运动表现。低能量可用性指扣除运动消耗后，剩下的能量不足以满足身体的需要。 | [Q37 跑量增加时留意能量不足](../book/06-training-health.md#q37) |
| 湿球黑球温度（WBGT） | 用于估计环境热负荷的指标，综合考虑气温、湿度、日照等影响。赛场的应对标准看当地组织方。 | [Q356 热天怎么调整](../book/training-health/06-emergencies-and-weather.md#q356) |
| 自动体外除颤器（AED） | 用于心搏骤停急救的设备。开机后会提示贴片、分析和后续操作。 | [Q354 成人倒地时怎么做](../book/training-health/06-emergencies-and-weather.md#q354) |
